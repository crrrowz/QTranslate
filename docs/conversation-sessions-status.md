# تقرير ميزة Conversation Sessions — وين وصلنا وشنو باقي

آخر تحديث: 2026-10-22 · الفرع: `feature/live-conversation` (8 commits، 61 ملف، ما انرفع للـ GitHub)

## 1. الخلاصة

QTranslate صار عنده صفحة **Conversation Sessions** تسجّل مكالمة ديسكورد بمسارين منفصلين (المايك وصوت المكالمة)، وتحوّل الكلام لنص، وتترجم أي كلمة بمجرد تمرير الماوس عليها. التحويل لنص صار عن طريق إضافة مستقلة اسمها **Speech Recognition**، تشتغل ويا أي مزود (سحابي أو محلي). وصار بيها **نص مباشر** من سيرفر Vosk محلي: الكلام يطلع بعد حوالي ثانية بدل 25 ثانية، وبعدين يتبدل بنص أدق (الوضع الهجين).

## 2. شنو انسوّى

### التسجيل والجلسات
- تسجيل المايك (Java Sound) وصوت النظام عن طريق **WASAPI loopback** (سكربت PowerShell، بدون مكتبات إضافية)، كل واحد بملف WAV مستقل ينكتب أول بأول.
- تقطيع الكلام عند السكوت بكاشف صوت يتأقلم ويا مستوى الضوضاء.
- إيقاف مؤقت واستئناف وإيقاف وحفظ. الجهاز اللي ينفصل يوگف بس مساره، والجلسة اللي انقطعت بسبب crash تنسترجع ويا صوتها.
- قائمة جلسات: بحث بالنصوص، وإعادة تسمية، وتصدير، وحذف.
- خيار "Keep recordings" للخصوصية، وتنبيه خصوصية واضح.

### التحويل لنص
- إضافة **Speech Recognition** مستقلة (منفصلة عن AI Services) بمجموعتين:
  - **Live text:** محرك مباشر (Off أو Vosk) ويا رابط السيرفر ولغة الـ Auto-Detect.
  - **Accurate text:** مزود دقيق، أو None (نص مباشر بس)، أو Groq، أو OpenAI، أو Deepgram، أو Whisper محلي، أو Custom متوافق ويا OpenAI، أو موديل دردشة صوتي (Gemini وغيره عبر gateway).
- زر Test connection يفحص اللي بالشاشة مو المحفوظ، ويفحص الرابط والمفتاح والموديل بسرعة.
- لغة منفصلة إلك ولغة للمكالمة.
- المقاطع اللي تفشل تنحفظ ويا صوتها ويا زر **Retry failed**.
- لحد 3 مقاطع تنرسل بنفس الوقت، حتى المزود البطيء ما يسبب طابور.

### النص المباشر والوضع الهجين
- واجهة جديدة بالـ API: `LiveSpeechRecognizer` (دور `LIVE_SPEECH_RECOGNIZER`).
- عميل Vosk بنفس بروتوكول `vosk_server.py` (WebSocket محلي).
- النص الجزئي يطلع بشريط مباشر، والسطر المنتهي يطلع بخط مائل لحد ما يوصل النص الدقيق ويتبدل.
- إذا انقطع السيرفر، يرجع للطريقة العادية وما يضيع شي، ويعيد الاتصال تدريجياً.

### الترجمة والتشغيل
- تمرير الماوس على كلمة يطلّع ترجمتها وترجمة الجملة كاملة. الترجمات تنحفظ مؤقتاً والطلبات المكررة تتوحد.
- تظليل عبارة يترجمها، وزر **Meanings** يجيب المعاني من القاموس.
- تشغيل السطر أو الكلمة الوحدة (إذا المزود يرجّع توقيت الكلمات، مثل Groq و whisper-1 و Vosk).

### سيرفر Vosk (بمشروع Vosk-STT-Chrome-Extension)
- خيارات جديدة: `--host` و `--session-timeout 0` و `--preload` و `--no-words`، وتوقيت الكلمات بالنتائج. إضافة Chrome تبقى تشتغل عادي.
- `Dockerfile`، وحاوية `vosk-stt` شغالة على `ws://192.168.85.129:8765` ويا موديلين: عربي (`ar-0.22-linto`) وإنجليزي (`en-us-0.22-lgraph`).

## 4. التحويل المحلي للمستخدمين: شلون يشتغل عندهم؟

**الوضع الحالي:** النص المباشر يحتاج سيرفر Vosk منفصل (Python أو Docker). هذا مناسب إلك، بس مو للمستخدم العادي.

**التوصية: Vosk مدمج داخل الإضافة نفسها.**
- Vosk إله مكتبة Java رسمية (`com.alphacephei:vosk`، رخصة Apache-2.0) بيها الملفات الأصلية لـ Windows و Linux و macOS. يعني تشتغل جوه البرنامج: **بدون Docker، وبدون Python، وبدون سيرفر.**
- المستخدم ينصّب إضافة Speech Recognition (موجودة ويا البرنامج أصلاً)، ويختار **Live engine = Vosk (built-in)**، ويختار لغة، والإضافة تنزّل الموديل بموافقته (الصغير حوالي 40 لـ 50 MB لكل لغة، والكبير أدق) وتخزنه بمجلد بيانات الإضافة.
- واجهة `LiveSpeechRecognizer` اللي سويناها تسمح بإضافته كمحرك ثاني بدون ما نغيّر المسجل أو الواجهة.
- **الكلفة:** حجم الإضافة يزيد بحوالي 7 لـ 20 MB بسبب الملفات الأصلية. وتحتاج إدارة موديلات بالإعدادات (تنزيل، وتقدّم، وحذف، واختيار حجم).

**خيارات السيرفر تبقى للمتقدمين:**
- **بدون Docker:** `pip install vosk websockets` وبعدين `python vosk_server.py`. موثق بالـ wiki.
- **ويا Docker:** للي يريد يشغّله على جهاز ثاني أو VM، مثل وضعك هسه.

**الخلاصة:** المستخدم العادي ما لازم يعرف شنو Docker. المحرك المدمج يخلي الإضافة كاملة وذكية من التنصيب: نص مباشر محلي فوراً، ونص دقيق (Groq أو غيره) اختياري فوقه.

## 5. شنو باقي (بالأولوية)

1. **تجربتك للنص المباشر بالبرنامج:** تفعيل Vosk بالإعدادات والتسجيل بالعربي والإنجليزي.
2. **Vosk مدمج بالإضافة** (التوصية فوق): مكتبة `com.alphacephei:vosk`، ومحرك "Vosk (built-in)"، وإدارة تنزيل الموديلات.
3. **لغة تلقائية للنص المباشر:** Vosk ما يكشف اللغة. ممكن نشغّل موديلين ونختار الأوثق، أو نستخدم اللغة اللي يكشفها المزود الدقيق.
4. **فصل المزودين حسب النوع، وإضافة نص مباشر سحابي:**
   - **Whisper-style (دفعة):** يرسل مقطع كامل ويرجع النص مرة وحدة. هذا كل مزودي "Accurate text" الحاليين (Groq، و OpenAI whisper-1، و Deepgram prerecorded، وسيرفرات Whisper، وموديلات الدردشة). مستحيل يصيرون مباشرين مهما كانوا سريعين.
   - **Realtime (بث):** اتصال مستمر يرجّع النص وانت تحچي. هسه Vosk بس. ويمه مزودين سحابيين يدعمون هالشي: Deepgram live، و OpenAI Realtime (gpt-4o-transcribe)، و AssemblyAI streaming، و Google STT streaming.
   - **المطلوب:** كل مزود يعلن قدراته (دفعة، مباشر، توقيت كلمات، كشف لغة)، والواجهة تعرض بكل مجموعة بس اللي يناسبها. وقائمة "Live engine" تشمل المزودين السحابيين المباشرين، كل واحد كتنفيذ لـ `LiveSpeechRecognizer`.
5. **ترجمة نصوص الواجهة للغات الباقية:** هسه العربي والإنجليزي بس، والباقي يرجع للإنجليزي.
6. **مشاكل منفصلة لگيناها بالطريق:**
   - OCR بإضافة System Services يطلّع خطأ `Join ... Value cannot be null` (ما إله علاقة بهالميزة).
   - الخلل بالرسم بالنافذة الرئيسية لما يكون Direct3D شغال (يحتاج تأكيدك).
7. **النشر:** رفع الفرع وفتح Pull Request لما تقرر.
