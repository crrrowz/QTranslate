# تدقيق الموديلات المحلية (Vosk) وربطها بـ Conversation Sessions

آخر تحديث: 2026-10-27 · الفرع وقت التدقيق: `fix/transcript-stability` · النوع: قراءة كود فقط، ما انبنى ولا انشغل شي

الهدف: أي شخص ينزّل البرنامج يگدر يشغّل التحويل المحلي بدون مشاكل. هذا التقرير يوصف شلون مربوط الموديل المحلي بالجلسات، وشنو الخلل، ويقسّم الإصلاح لمهام. البرومبتات الجاهزة للتنفيذ بـ [local-models-fix-prompts.md](local-models-fix-prompts.md).

> **تنبيه صادق:** كل شي هنا من قراءة الكود. مشكلة "زر التنزيل ما يطلع" **ما تأكدت بالتشغيل**. سجّلت أقوى الأسباب المحتملة، وأول خطوة بالمهمة 1 هي إعادة إنتاجها.

## 1. شلون مربوط الموضوع (المسار الكامل)

```
Settings > Plugins > Speech Recognition (DynamicPluginSettingsDialog)
   │  dropdown voskBuiltinModel + أزرار @PluginAction (Download/Import/Delete/Check)
   │  ظهور الأزرار: دالة <action>Visible() على نسخة عمل فيها القيم اللي على الشاشة
   ▼
SpeechSettings ──► VoskModelManager (تنزيل، فك ضغط، isInstalled، findModelForLanguage)
   │
SpeechPlugin.onEnable ──► services:
   ├─ SpeechRecognitionService (دور SPEECH_RECOGNIZER)  ← بالوضع المحلي يحوّل لـ VoskBuiltinService.transcribeClip
   └─ VoskLiveService (دور LIVE_SPEECH_RECOGNIZER)       ← يوجّه لـ VoskBuiltinService.openSession
                                                            (أو Deepgram / OpenAI Realtime)
   ▼
core: ConversationFeature
   ├─ openLive(language)   → LiveSpeechRecognizer.openSession
   ├─ recognize(request)   → SpeechRecognizer.transcribe  (التحقق الدوري + المقاطع العادية)
   └─ speechLanguages()    → اللغات = لغات الموديلات المنصّبة بس
   ▼
ui-swing: ConversationWindow (قائمة اللغات، شريط حالة الخدمة، تنبيهات RecorderNotice)
```

الملفات الأساسية:
- `plugins/speech-services/.../VoskModelManager.kt` (686 سطر): الكتالوج، التنزيل القابل للإيقاف، فك الضغط، الحذف، الاستيراد.
- `plugins/speech-services/.../VoskDownloadDialog.kt`: نافذة التقدم.
- `plugins/speech-services/.../VoskBuiltinService.kt`: تحميل الموديل (كاش LRU لموديلين)، الجلسات الحية، تفريغ المقاطع.
- `plugins/speech-services/.../SpeechSettings.kt` و `SpeechPlugin.kt`: الإعدادات، الأزرار، دورة حياة الإضافة.
- `ui-swing/.../settings/panels/DynamicPluginSettingsDialog.kt`: رسم الإعدادات وظهور الأزرار (`updateVisibility`, `createWorkingCopy`).
- `core/.../conversation/ConversationFeature.kt` و `ConversationRecorder.kt`: الربط بالجلسة.

## 4. قرارات تحتاجك

1. **المهمة 3:** تريد زر "تنزيل" مباشر داخل نافذة الجلسة (أسهل للمستخدم)، لو بس رسالة ويا زر يفتح الإعدادات (أبسط بالتنفيذ)؟ البرومبت مكتوب على الخيار الثاني كبداية، والأول كخطوة اختيارية.
2. **المهمة 4:** بالوضع المحلي، النص يبقى "غير مدقق" (صادق)، لو تريد خيار "تدقيق محلي بموديل أكبر" (مثلاً صغير مباشر + كبير للتدقيق)؟ البرومبت ينفذ الصادق بس.
3. **المهمة 5:** تحميل الموديل: وقت فتح نافذة الجلسة (أسرع ببداية التسجيل)، لو وقت أول تسجيل (أقل ذاكرة)؟ البرومبت يختار وقت فتح النافذة.
